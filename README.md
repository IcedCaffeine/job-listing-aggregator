# Job Listing Aggregator & Scraper

A Python project to scrape job postings from various websites, clean the data, and display it on a dashboard.

## Features

- Scraping job listings from multiple websites
- Data cleaning and storage
- A simple web interface for display (coming soon)

## Setup Instructions

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Run the application with `python src/main.py`.
